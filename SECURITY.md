# Security policy

zstack is Markdown, shell scripts and hooks that run on your machine inside Claude Code, so the realistic risks are a script that runs something it shouldn't, or a skill that leaks data.

## Reporting a vulnerability

Please report it privately through GitHub: **Security → Report a vulnerability** on this repository. Don't open a public issue. You should get a reply within a week.

## Supported versions

Only the latest release on `main`.
